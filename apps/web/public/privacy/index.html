RAVAN

Your collection stays personal.

RAVAN is a private, single-owner cinema application operated by its account owner. This notice describes the current personal deployment. Updated 23 November 2026.

Google and your library

Google sign-in identifies the configured owner. With your consent, RAVAN requests read-only Google Drive access to discover and stream files from the library folder you select. This Google permission covers reading Drive files; RAVAN does not request permission to edit or delete them. Authentication tokens stay on the backend and are encrypted at rest.

What the server stores

The application stores library metadata, selected folder information, playback and reading progress, watchlist choices, device registrations and security records. It keeps an encrypted authenticator seed and hashed recovery codes. Movie and book byte ranges may be cached in a private server directory for playback and reading. Metadata backups are encrypted; they do not include the media cache. Posters and pictures are made on the server from each film's own cover or from frames of the film, and are kept with the library.

Reading on a paired Apple device

When the owner grants Reading Room access, the app opens the books and comics in the connected Drive folder and saves reading positions on this server. The app keeps its device credential in the system Keychain. The embedded reader uses a temporary session held in memory. Removing the paired device in Your cinema ends its reading access.

Optional film artwork from TMDB

Off unless the owner turns it on. When it is on, the server sends each film's title and year to The Movie Database (TMDB) to find its poster and backdrop, and downloads them itself; browsers and televisions only load them from the owner's server. This product uses the TMDB API but is not endorsed or certified by TMDB.

Hosting and use

The interface and API routing use Cloudflare. Video delivery uses the owner's server directly over HTTPS. Google provides identity and Drive services. Those providers process connection data under their own policies. RAVAN does not sell Google user data, use it for advertising or use it to train AI models. The deployment has no third-party advertising or analytics scripts.

Retention and control

Library metadata and authentication records remain until the owner removes them. Cached movie ranges are evicted as space is needed. Scheduled encrypted backups retain up to fourteen daily copies. Signing out ends the browser session; it does not delete library data or revoke Google's grant. You can revoke RAVAN's Google access in Google Account connections. The operator can remove stored application data and backups on request.

Contact

For privacy questions or removal of stored application data, use the support address shown on Google’s RAVAN consent screen.
