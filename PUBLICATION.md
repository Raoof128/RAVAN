# Public source release

This repository contains the application source, tests, fictional demo artwork and reusable deployment templates. Deployment domains are examples that must be configured for your installation. Set the Apple app’s default website in `apps/apple/Ravan/Paired/RavanWebsite.swift`. The app can also pair with a custom HTTPS server. Personal server records, historical deployment reports, credentials, databases, backups and personal media files are excluded. The Apple client includes an original 90-second film, Tide Almanac, with a synthesized soundtrack and English and Persian captions. Its sources and provenance are described in the [sample notes](apps/apple/Sample/README.md).

The first public commit is a clean source snapshot. Earlier private operational history remains with the maintainer. No runtime secrets are needed to build the frontend preview or run the isolated tests.
